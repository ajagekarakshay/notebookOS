Retrieval-augmented synthesis

October 7, 20266 linksresearch · retrieval

The central question is no longer whether a system can retrieve relevant material, but whether it can preserve the shape of evidence while composing an answer. A useful notebook should make that provenance visible at the moment an idea is written.

Working hypothesis. Synthesis quality improves when claims retain addressable links to both source passages and the intermediate notes that transformed them.

Evidence path

A source enters the workspace as an attachment or web reference. Highlights become stable block targets; working notes link to those targets; the final synthesis links to the working notes. Backlinks then expose where each observation influenced later work.
